# New Dawn first-release design

The user's supplied design is the implementation brief: adapt the existing isolated static foundation, preserve the original project, use newdawnlol.com and publish only the home and release-date intent pages first. No new Astro project, SaaS, authentication or payments.

Shared JSON source data feeds one Node renderer. Published routes alone enter the sitemap. Per-route dates are authored, not generated. es/pt/tr remain disabled with explicit translation groups reserved for future reciprocal alternates. Seven additional topic intents stay unpublished.

The interface uses a dark editorial layout, gold accents, an original CSS horizon, clear evidence labels, visible sources, a timeline and native FAQ disclosures. All facts remain readable without JavaScript. Images are original, and artworkCleared stays false pending operator review.

Build validates origin, fields, dates and source references before replacing dist. Tests cover publication scope, metadata, source-backed timing, stale-content removal, links and invalid configuration. Browser checks cover mobile/desktop layout and FAQ behavior. Live publishing, domain binding and GSC are separate operational checks, never inferred from a passing local build.

Retain TimeLord/dburr attribution and CC BY-SA 4.0, with a noindex About page. Remove timer scripts, routes, rules, vendor artwork and PWA. Preserve the old source copy in an external archive before conversion.
